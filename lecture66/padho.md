conditional rendering: it is conditionally rendering the component based on the state of the application. It is a common pattern in React applications to show or hide components based on certain conditions.

 For example:
 
 1. you might want to show a loading spinner while data is being fetched, and then show the actual content once the data has been loaded.

2. you might want to show a login form if the user is not authenticated, and show the user's profile and log out button if they are authenticated.
